2. Goals → Conversions: successful-enquiry conversion status, primary/secondary setting, campaign goal selection, and the expected tag/destination. A tag in website code does not prove Google received a valid conversion. Zero recorded conversions is not proof of zero real enquiries.
3. Performance Max channel report and search terms: whether the campaign is serving on Search, which terms trigger it, and which landing pages receive traffic.
4. Search Console URL inspection of the L-sealer URL: indexed status, selected canonical, last crawl and any exclusion reason. Performance report filtered to this page and L-sealer queries: impressions, position, clicks and country/device context.
