# Search Console follow-up

The prompt supplies an aggregate baseline for roughly three months: 340 organic clicks, about 8,730 impressions, 3.9% CTR, average position 11.7, 335 indexed URLs and 529 not indexed. The figures are owner-provided and were not independently retrieved. An older separate screenshot baseline exists in `search-expansion-2026-09-28.md`; keep time periods and sources separate.

## Required exports

1. Export Performance by page and query for the same date range, plus a prior-period comparison. Segment brand/non-brand, device and country.
2. Export or copy exact examples from each indexing bucket: discovered-not-indexed, crawled-not-indexed, duplicate, redirect and not found. Include Google's selected canonical where available.
3. Compare each example to `SEO_URL_INVENTORY.csv` and its intended canonical. Classify as priority machine/category, useful editorial, location enquiry utility, duplicate, obsolete, redirect, thin/other.
4. Inspect the production sitemap status and a representative URL from each page template. Record status, canonical, robots, rendered content and internal discovery path.
5. Prioritize useful canonical pages and fix evidence-backed defects. Do not seek indexing for every district or every generated URL solely to reduce the excluded count.

## Measurement after release

Track canonical product/category pages and their query families separately. Review impressions, clicks, CTR, position, indexed preferred URLs and qualified CRM enquiries. Evaluate by cohort and time range; do not promise rank changes or interpret short-term movement as causal proof. Verify analytics and consent before relying on event counts.
